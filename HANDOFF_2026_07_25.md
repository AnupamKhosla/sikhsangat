## What shipped this session
- **Offline UX** (`src/mirror-utils.js` rewrite rules + `OFFLINE_STYLE_CONTENT`/`OFFLINE_SCRIPT_CONTENT`): reply form, compose area, quote/report, login/register, guest-terms bar, share/follow are hidden or dead. `offline-mirror.js` adds a runtime capture-phase click blocker for dead `data-action`s.
- **CRITICAL fix — invisible topic comments.** Posts rendered at height 0. Root cause is NOT our hide rules: IPS's own CSS sets `form[data-ipspageaction]` / `form[data-role="moderationTools"]` (the wrapper around every post) to `display:none`, expecting JS to reveal it for logged-in mods; offline that JS never runs, so all comments collapsed. Fix = CSS override in `OFFLINE_STYLE_CONTENT` forcing that form + `#elPostFeed` to `display:block; opacity:1; pointer-events:auto`. Because that CSS is the external file `docs/_offline/offline-mirror.css`, the fix hits ALL pages from ONE `ensureOfflineSupportFiles()` call — verified 9/9 posts visible. Do NOT re-run a 3000-file repair for CSS-only changes.
- **Scraper perf** (`src/main.js`): shared browser context via `ensureContext()` (was a new context per page → slow + "browser closed" crashes). Blacklisted `/html5shiv` + `/contact/` from the asset queue (`BLOCKED_ASSET_PATTERNS` + `isBlockedAsset`) — they spammed a 404 and an HTML response on every page. Fixed `.xml/` trailing-slash ENOENT in `mirror-utils.js getLocalPath` (strip trailing slash before the no-extension branch).
- **VRT** (`scripts/vrt-compare.js`): pixelmatch live-vs-clone over homepage/forum/topic. Live page is masked with the same hidden elements so the diff measures true rendering fidelity, not our intentional hides.
